# Networking Fundamentals

## Task 1 and Task 2 command evidence

Run these commands in a Linux terminal and paste the output below each command. These are standard commands commonly used in the shared DevOps practice repository.

```bash
ip addr
ip route
ping -c 4 8.8.8.8
ss -tuln
nslookup google.com
curl -I https://example.com
traceroute example.com
```

## Understanding

- `ip addr` displays network interfaces and assigned IP addresses.
- `ip route` displays the routing table and default gateway.
- `ping` checks reachability using ICMP packets.
- `ss -tuln` lists listening TCP and UDP sockets without resolving names.
- `nslookup` queries DNS for a hostname.
- `curl -I` requests only HTTP response headers.
- `traceroute` shows the hops between the local machine and a destination.
